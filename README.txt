BCR STUDIOS WEBSITE — STARTER FILES

FILES
- index.html: website content and sections
- style.css: design, colours and responsive layout
- script.js: mobile navigation and current year

HOW TO CUSTOMIZE
1. Open index.html in a text editor.
2. Replace the placeholder email hello@bcrstudios.example with your real email.
3. Add your real music/video/game links to the relevant sections.
4. You can change text, colours and images in the files.

FREE PUBLISHING OPTION: GITHUB PAGES
1. Create or sign in to a GitHub account at https://github.com/
2. Create a new public repository named bcr-studios-website.
3. Upload index.html, style.css, script.js and README.txt to the repository's root.
4. Open the repository's Settings → Pages.
5. Under build/deployment, select "Deploy from a branch".
6. Choose branch "main" and folder "/ (root)", then save.
7. Wait for the site to publish. GitHub will show the public website URL in Settings → Pages.
   It will typically look like https://YOUR-USERNAME.github.io/bcr-studios-website/

NOTES
- GitHub Pages supports static websites and is free for public repositories on eligible plans.
- You do not need to buy a custom domain.
- External fonts/images may use internet data and third-party services. You can replace or remove them.
- The contact email is a placeholder until you replace it.
